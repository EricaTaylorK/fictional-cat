# PawLedger

Local hours log (Vite + React). Enter a date, short task label, and CapEx or OpEx. Edit or delete entries. Totals stay at the bottom. Data lives in this browser via `localStorage` — no account, no server.

Remote: [github.com/EricaTaylorK/fictional-cat](https://github.com/EricaTaylorK/fictional-cat)

## Run

```bash
npm install
npm run dev
```

Open the URL it prints (usually `http://localhost:5173`).
